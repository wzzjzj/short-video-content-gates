# 参考视频分析模式

## 目的与状态

把参考视频转化为可复核的研究输入，而不是模仿指令。该模式应回答：视频交付了什么、怎样推进、证据和画面如何服务论点、为什么可能有效、哪些机制能迁移到当前账号，以及迁移后必须改变什么。

结果状态：

- `COMPLETE`：内容、时间结构、视听证据、可迁移机制和账号适配均有足够证据。
- `PARTIAL`：仍可形成有限结论，但缺少完整视频、音频、转录、关键画面、来源数据或其他重要证据。
- `UNUSABLE`：输入不足以支持可靠分析，例如只有标题、封面或无法读取的链接。

状态只描述分析完整度，不代表参考视频值得采用，也不代替 intake 的 PASS、REVISE、BLOCK 或 EXCEPTION。

## 输入与证据等级

优先使用用户提供或授权访问的原视频/完整视频文件。保持原素材只读，转录、抽帧、代理文件和报告写入新的分析位置。

按证据强度区分：

1. 完整视频、原始音频、带时间码转录、关键帧或分场结果：可支持全片结构和视听关系判断。
2. 可连续播放的公开页面：可支持实际观看到的片段；平台指标需记录观察时间和口径。
3. 节选、录屏或局部片段：只支持片段级结论。
4. 标题、封面、文案、单张截图或他人摘要：只能支持包装和可见信息判断，不能推断完整内容、节奏或“为什么有效”。

平台公开互动数、热门标签和排名只证明观察时的表现，不证明由某个结构、镜头或文案导致。没有账号后台数据时，不得推断留存曲线、流量来源或转化原因。

## 分析流程

根据可用工具选择等价方法，不把某个程序写成唯一依赖。

### 1. 核验输入

记录来源、作者/账号（可确认时）、观察日期、文件时长、画幅、编码或其他可验证参数。文件可用时记录哈希；转载或录屏应标明，不把它当作原始发布文件。

### 2. 建立三路证据

- 语义：获取带时间码转录，区分自动识别、人工校正和无法听清部分。
- 时间/节奏：记录关键段落、明显转折、信息任务变化；可用场景变化检测辅助，但算法检出数不等同于真实镜头数。
- 视觉/声音：固定间隔采样覆盖全片，再在开头、转折、演示、结论和高密度段补关键帧；记录口播、字幕、实拍、界面、图表、动画、音乐和音效各自承担的功能。

若某一路不可用，继续分析可证实部分并将结果降为 `PARTIAL`，不得补写未观察到的内容。

### 3. 复原内容结构

按时间段记录每一段的认知任务，而不是只做剧情摘要：

- 当前提出或回答什么问题？
- 交付的结论、事实、案例、演示、方法或体验是什么？
- 画面和声音是在证明、解释、演示、转场、制造情绪，还是只作包装？
- 这一段如何推动下一段？

短视频至少精看前 2 秒、前 5 秒和结尾；长视频还要识别每次新问题、新答案或论证层级的变化。

### 4. 对齐承诺、论点、证据与画面

为每个核心结论建立可定位关系：

    观众问题/承诺 → 核心结论 → 支撑证据或推理 → 可执行动作或目标回报 → 对应画面/声音 → 适用边界

缺少支撑时标为“作者主张，当前未核实”；事实性、高风险或商业主张若用于当前项目，必须回到项目权威来源重新核验。

### 5. 解释“为什么有效”

只写有证据支持的机制，并区分观察与推断。可检查：

- 是否先呈现可感知的问题、结果、冲突或熟悉对象；
- 是否在承诺后持续交付新答案、证据、转折或演示；
- 是否把抽象概念变成数据、比较、实验、场景或操作；
- 画面变化是否服务理解，而非只追求频繁切换；
- 结尾是否回收开头承诺并形成搜索、收藏、评论、分享或行动理由。

高播放、高互动或“热门”不能单独证明以上任一机制。使用“可能贡献”“观察到”或“根据结构推断”，不要写成确定因果。

### 6. 提炼与适配

分别记录：

- 可迁移机制：可跨作品复用的结构、论证、节奏或画面职责。
- 不可直接复制：具体文案、镜头顺序、人物表演、品牌资产、受保护素材、独特视觉识别及未经许可的声音/音乐。
- 当前账号变化：结合项目适配层说明受众、核心承诺、时长、事实来源、表达语气、画幅、平台安全区和资源条件需要怎样改变。
- 差异化方向：给出 1–3 个真正改变观点、受众入口、证据、场景或表达方式的方向；换标题、换颜色或缩短原片不算差异化。

不得因为参考视频是教程，就强迫叙事、情绪或展示内容加入操作步骤；迁移仍须服从当前内容类型。

## 质量检查

`COMPLETE` 至少满足：

- 输入来源和分析范围明确；
- 全片或声明范围内有时间码结构；
- 核心结论能定位到证据或被标注为未核实主张；
- 画面/声音职责不是凭单张截图推断；
- “为什么有效”区分观察与因果推断；
- 可迁移机制和不可复制元素分别列出；
- 已结合当前项目适配层给出变化，而非直接复刻；
- 明确下一步仍需执行 intake。

任一关键项缺失时使用 `PARTIAL`；输入不足以支持内容或结构分析时使用 `UNUSABLE`。

## 单例与稳定性

一次成功分析只证明该样本可用，不证明模式跨题材稳定。首次固化或大幅修改后，至少用两种在内容类型或表达结构上明显不同的参考视频做前向验证。两次都能在不臆造证据的前提下产出完整结果，才可描述为“初步稳定”；仍不能据此承诺热门或爆款。
